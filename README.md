# portfolio-KrithikaDharanikota
Krithika Dharanikota — portfolio site 🐞

Personal portfolio site showcasing my background in generative AI, machine learning research, and software engineering — including experience, projects, and publications.

Overview
About — background and education (M.S. Computer Science, USC; B.E., SSN College of Engineering)
Experience — roles across USC Cinematic Arts, USC ICT, and USC ISI, plus prior internships
Work — selected projects spanning ML research pipelines, evaluation tooling, and applied engineering
Publications — CVPR 2026, IAES International Journal of Artificial Intelligence (2025), FIRE 2023
Skills — organized by generative AI/LLMs, ML & research, engineering/infrastructure, and data pipelines
Contact — email, LinkedIn, GitHub

The site supports automatic light/dark mode based on system preference and includes subtle scroll-based animations.

Tech Stack

Built with vanilla HTML, CSS, and JavaScript — no frameworks or build tooling. This keeps the site lightweight, fast to load, and easy to host and maintain long-term.

Running Locally
bash
python3 -m http.server 8000

Then open http://localhost:8000.

Deployment

Hosted via GitHub Pages, deployed from the main branch. To update:

Edit index.html
Commit and push to main
GitHub Pages redeploys automatically within a couple of minutes
